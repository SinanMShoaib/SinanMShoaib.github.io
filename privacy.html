Privacy Policy

Shorts Uploader · Effective 17 October 2026

Summary

Shorts Uploader is a private tool used by one person to upload videos to their own YouTube channel. It has no other users. It collects no personal information from anybody, stores nothing on a server, and shares nothing with anyone.

Who this covers

The only user of this application is its owner and author. The application is not distributed, not published to an app store, and not accessible to the public. If you are reading this page, you are not a user of the application — this policy exists to satisfy Google’s requirement that any application using OAuth publish one.

What the application accesses

With the owner’s explicit consent through Google’s standard OAuth consent screen, the application requests these scopes on the owner’s own Google account:

  • youtube.upload — to upload video files to the owner’s own YouTube channel.
  • youtube.readonly — to read back basic details of the channel and its own uploads, in order to confirm an upload succeeded and to avoid uploading the same video twice.

How that data is used

Access is used for one purpose only: publishing the owner’s own videos to the owner’s own channel, and verifying that those uploads completed. It is never used for any other purpose.

Where data is stored

The application runs entirely on the owner’s personal computer. There is no server, no hosted database, and no cloud storage. The OAuth token Google issues is written to a single file on that computer and is used only to authenticate the owner to Google. Video files and the application’s own records stay on that same machine.

What is never done

  • No data is sold, rented, or traded.
  • No data is transferred to third parties, advertisers, data brokers, or analytics providers.
  • No data is used to build profiles, train models, or target advertising.
  • No information is collected from visitors to this website. This site is static and sets no cookies.

Limited Use

The application’s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

The stored OAuth token is kept only while the application is in use and is deleted whenever the owner signs out or removes the file. Access can be revoked at any time from the owner’s Google Account permissions page, which immediately and permanently ends the application’s ability to reach the account.

Children

The application is not directed at children and has no users other than its adult owner.

Changes

If this policy changes, the revised version will be posted on this page with a new effective date.
